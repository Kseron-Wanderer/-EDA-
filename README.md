# -EDA-
Разведочный анализа данных (EDA) цен на квартиры с использованием Python
Репозиторий содержит два файла:
- appartamentsearch.py (непосредственно файл исполнения на python)
- apartments.csv (учебная БД)

В результате исполнения файла будут отображены 3 инфо-графика:
1. Распределение цен на квартиры,
2. Зависимость цены от жилой площади квартиры,
3. Тепловая карта корреляции признаков.
